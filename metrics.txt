Our dataset:
Human: 818,613
Bot:   115,259

Issues? 7:1 ratio, any model will have difficulty learning patterns when guessing human will result in ~85% acc
    - Prevelant in our KNN testing with a resampling with a ration of 7:1 just scaled down
        - It got a 88% but recall was almost a perfect 1, meaning it guesses human every time

Solution: Undersampling the majority class to make a 2:1 ratio

Other constraints:
    Storage: TwiBot22 dataset has a sum total of over 100gb
        We only got unique users and one tweet per user, still over 1 billion lines
        Bot to Human ratio not great given bots might have had more tweets
            - We also lack some strong features gathered from multiple tweets attached to one user

            - LOWKEY we could've chosen a small subset of human and bot users and gathered a set limit of tweets for each user
                this would have solved the one tweet per user issue, but we could just say we wanted to recreate the other dataset we had
                that had one tweet per user

    Time: Each run through a model took about ~1 hour on average

Scores:
    MCC: a measure of classifier performace
        -1 to 1
        closer to 1 means a good classifier
        0 means no better than guessing
        -1 poor performance

        >0.3 is considered moderate
        >0.5 is considered strong

Balanced accuracy averages the recall of each class equally regardless of size:
balanced accuracy = (bot recall + human recall) / 2
